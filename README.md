# My Python Utilities
A collection of personal Python scripts and tools for finance, automation, and home server management.

## Tools Included

### 1. Poor Man's Coverd Call Validator (Stok Option's Strategy) (`validator.py`)
A standalone desktop GUI app to validate Diagonal Spreads (Poor Man's Covered Calls).
- **Language:** Python 3 (uses `tkinter`)
- **How to run:**
  1. Navigate to the folder.
  2. Run `python validator.py`.
